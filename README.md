# Basilisk Resources – Granular Flow Simulations

Resources associated with a research project on the numerical simulation of granular flows using [Basilisk]([https://basilisk.fr/](https://basilisk.fr/sandbox/Kilian/)).

The project focuses on numerical modelling, convergence studies and comparisons with experimental results and other numerical approaches, including SHALTOP and HYSEA.

## Documents

* **[Research Report](Rapport_POLGE_POULICHET_Kilian.pdf)** – Complete report describing the methodology, numerical simulations and results.
* **[Presentation](Presentation_POLGE_POULICHET_Kilian.pdf)** – Presentation summarizing the project and its main findings.

## Resources

The [ressources](ressources/) directory contains figures and illustrations used in the Basilisk documentation and numerical comparisons.
